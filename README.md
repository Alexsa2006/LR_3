# Лабораторні роботи 0-3 з Java

Цей Maven-проєкт містить розв'язання лабораторних робіт 0-3.

## Запуск

```bash
mvn compile
mvn exec:java -Dexec.mainClass="ua.example.lab0.HelloWorld"
mvn exec:java -Dexec.mainClass="ua.example.lab2.MatrixApp"
mvn exec:java -Dexec.mainClass="ua.example.lab3.Run"
```

Якщо плагін Maven Exec недоступний, запустіть класи в IntelliJ IDEA. Для коректного відображення українського тексту використовуйте кодування UTF-8 у редакторі та консолі.

## Лабораторна робота 1

Проєкт підготовлено для роботи з Git. Створіть репозиторій на GitHub, підключіть його в IntelliJ IDEA та завантажте проєкт. Кожну нову лабораторну роботу виконуйте в окремій гілці, наприклад `LR_3`, а потім об'єднуйте її з `master` або `main`.
